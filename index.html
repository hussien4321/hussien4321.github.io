01

Partybox

In progress

A web platform for party games. The game itself runs on whatever screen the room is already looking at — a TV, a laptop — and every player uses their own phone as a controller. Built for the Korean market, so the interface is in Korean throughout.

  • Architected the platform so each game is a self-contained module that plugs into shared infrastructure — lobby, networking, player state, screen flow. New games drop in without touching the core.
  • Designed the host↔client layer so a big screen and a pocketful of phones exchange state and drive game logic in real time, through a single document and no direct connection.
  • Built per-state animation with GSAP, so every phase of every game — prompt, wait, reveal, score — gets its own beat.
  • Designed the party games themselves, drawing on years of board gaming.
  • Used Claude Code throughout to move faster and ship updates quickly.

02

Word VS

Flutter · Firestore

Wordle, with the bit it was missing: a second player. Both of you get the same word at the same time and race for it.

  • Built the guessing mechanic and the tile-reveal animation in Flutter — the flip that colours each letter is the whole feel of the game, so it got the attention.
  • Added real-time networking for head-to-head play, with both boards resolving against one shared session.
  • Laid the game out as a BLoC-per-mode architecture over repository interfaces, so the solo and two-player screens share one engine and differ only in what drives it.
  • Scheduled automatic cleanup of stale sessions every three days, to keep storage costs flat over time.

03

FireFit

Full stack

A social platform for fashion: post the fit, the room rates it out of five flames. The biggest of these by some distance — a full social graph, a media pipeline and a custom backend behind it.

  • Built a follow system with push notifications, so new looks from people you follow reach you on the lock screen.
  • Built weekly and monthly trending feeds that surface the best-rated looks over a rolling window.
  • Added custom search by style, gender and country, plus personal lookbooks for saving favourites.
  • Wrote the backend as well as the app — 33 callable Cloud Functions in TypeScript over Google Cloud SQL, rather than letting the client talk to the database.
  • Built a media pipeline that thumbnails uploads server-side, so a feed of hundreds of outfits never pulls a full-size photo.

04

Fastball Battle

Game · CustomPainter

An endless baseball game: the pitch comes in, you get one tap to swing, three misses and you're out. Written without a game engine — every frame is drawn by hand onto a Flutter canvas.

  • Built a custom sprite-animation engine that composes each character from several image layers and drives them through a CustomPainter render loop — idle, swing, hit and death states for both fighters, plus the ball and the collision.
  • Added unlockable characters and stages, so a run that ends badly still moves you towards something.
  • Wired in-app purchases and ads around the loop, and shipped it.

05

Todo Today

Offline-first

A to-do app with one rule: every task you add is given exactly 24 hours. The clock starts the moment you write it down, and at the end of the day it's gone either way.

  • Built an animated 24-hour countdown on every task, since the deadline is the core of the product and had to be the first thing you see.
  • Added end-of-day local notifications nudging users towards unfinished tasks.
  • Built performance graphs from accumulated task history, so a week of use reads as a trend rather than a list.
  • Kept all data on-device in SQLite, with no account, server or sync to wait for.
